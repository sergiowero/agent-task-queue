# CountPill

A small neutral number pill that sits next to a title: a page title, a board column header or a tab.

- Pass the number as `children`. It uses `surface-tertiary`, 11px/600 and tabular numbers, and is at least 20px wide.
- Show counts of what's on screen ("12" projects, "3" in review). Don't use it for status. That's what Badge is for.
