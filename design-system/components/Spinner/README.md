# Spinner

The rotating loader glyph (`SpinnerIcon`) at `h-4 w-4` by default, inheriting the current text color.

- Size and color it with `className` (`h-3.5 w-3.5`, `text-primary`).
- Buttons and icon buttons render it for you through `loading`. Use Skeleton instead for content that is still loading.
- It keeps spinning under reduced motion.
