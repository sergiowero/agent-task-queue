# Icons

The portal's icon vocabulary: Lucide glyphs under stable, action-based names, exported from `lib/icons.ts` and here as `AgentQ.Icons`.

- Import icons by these names, never from lucide-react directly, so one action always gets one glyph (e.g. `ApproveIcon` and `SuccessIcon` are both CircleCheck, and `CloseIcon` and `CancelIcon` are both X).
- Add a new name here before using a new glyph anywhere.
