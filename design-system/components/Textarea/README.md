# Textarea

A multi-line text field with the same border, focus halo and error behavior as Input.

- It takes the usual textarea props plus `error`. Resizing is vertical only, and the line height is relaxed.
- For list-like inputs, ask for one entry per line in both the placeholder and the hint: "One constraint per line", "One criterion per line".
- Use a placeholder that describes the content: "Context, goals and anything the agent should know".
